# xiaok-tesla — LINE 定位分區機器人

依照你**所在位置屬於哪一區**，自動把該區 LINE 群組的**最近對話紀錄**和**未完成的單子**拉到你跟機器人的私訊裡。
你在私訊裡回的話，機器人會**自動轉發到那一區的群組**，並**標記（@）相關的人**。

```
 北區群組 ─┐                         ┌─ 你傳位置 → 判斷在「北區」
 中區群組 ─┼─► 機器人記錄所有訊息/單子 ─┤   → 拉出北區最近對話 + 單子
 南區群組 ─┘                         └─ 你打字回覆 → 推到北區群組並 @對方
```

## 功能

| 功能 | 怎麼用 |
|---|---|
| 依位置切換區域 | 私訊按「📍 傳送位置」，機器人找最近的區（`config/regions.json`） |
| 拉取最近對話 | 傳位置後自動顯示，或打 `/最近` |
| 單子 | 自動辨識群組裡的派工、交車、接送、維修、徵人支援等需求（見下方「單子怎麼判斷」）；`/單` 列出、`/完成 12` 結案 |
| 回覆到群組 | 私訊直接打字 → 以「💬 你的名字：內容」推到該區群組 |
| 自動標記 | ① 長按機器人轉來的訊息選「回覆」→ 自動 @原發話者，並送回**那則訊息所屬的群組**<br>② 打 `@名字` → @該成員<br>③ `@所有人` → @全部 |
| 即時轉發 | 你所在區有新訊息時即時私訊給你；`/即時 單` 只轉單子，`/即時 關` 關閉 |
| 指定群組抓關鍵字 | 在群組打 `/關鍵字 新增 交車 拖吊`，該群組改成只要訊息有這些字就記成單 |
| 權限控管 | 只有 `ALLOWED_USER_IDS` 裡的人能用私訊功能 |

## 安裝

需要 Node.js 22.9 以上（使用內建 SQLite），先執行 `npm install`。

1. **建立 LINE 官方帳號 / Messaging API channel**：<https://developers.line.biz/console/>
   - Messaging API 分頁：發行 **Channel access token**；記下 Basic settings 的 **Channel secret**
   - 開啟 **Allow bot to join group chats**
   - LINE Official Account Manager：關閉「自動回應訊息」、開啟「Webhook」
2. 設定：
   ```bash
   cp .env.example .env                       # 填入 secret / token
   # config/regions.json 已設定好：基隆市區，方圓 5 km
   npm start
   ```
3. 把伺服器公開成 HTTPS（正式環境用 Render / Fly.io / VPS；本機測試可用 `ngrok http 3000`），
   在 LINE Console 設定 Webhook URL：`https://你的網址/webhook`，按 Verify。
4. 把機器人加進各區群組，在群組裡輸入：`/綁定 北區`（區名要跟 `regions.json` 一致）
5. 自己加機器人好友，輸入 `/id` 取得 userId，填進 `.env` 的 `ALLOWED_USER_IDS` 後重啟。
6. 私訊按「📍 傳送位置」開始使用。

## 服務區域與跨群組找單

`config/regions.json` 目前是 **基隆**：中心在基隆火車站／廟口，半徑 5 km（八斗子約 5.2 km，要涵蓋就改成 6）。

機器人會掃描**所有它所在的群組**，依訊息裡的地名（`places`）判斷每張單跟哪一區有關，不需要一個區只綁一個群組：

- `基隆`、`七堵`、`八堵`、`暖暖`、`安樂區`、`仁愛區`、`八斗子`、`和平島`、`百福`、`廟口`、`正濱`
- 刻意不放「中山」「中正」「信義」，因為台北也有（例如「台北市中山北路」），會抓錯。
- 箭頭 `⬇️`、`→`、或「下車」之前是**上車點**，之後是**目的地**：
  - `基隆市中山二路105巷… 下車地址：台北市…` → 🚩 基隆上車（排前面）
  - `R 萬里區港東路152號 ⬇️基隆` → 🏁 送到基隆（排後面）
  - `F新莊榮華路 ⬇️台北` → 跟基隆無關，不會出現
- 只顯示 `ORDER_MAX_AGE_HOURS`（預設 6 小時）內、還沒 `/完成` 的單。

傳位置後，你會收到「最近跟基隆有關的單」，一張單一則訊息、標明來自哪個群組。**長按那張單選「回覆」**，打的字就會送回那張單原本的群組，並標記發單的人。

## 指定群組抓關鍵字

想要某幾個群組**只抓特定字眼**，就在那個群組裡設定關鍵字，其他群組不受影響：

```
/關鍵字 新增 交車 拖吊 接送     ← 可一次加多個（空白、逗號、頓號都可以分隔）
/關鍵字                        ← 查看目前的關鍵字
/關鍵字 刪除 接送
/關鍵字 清空                    ← 回到自動判斷
```

- 設了關鍵字的群組：訊息裡**有任一個字眼**（英文不分大小寫）才算單，單子上會標「📝 關鍵字：拖吊」。`#單`、`派單` 這類開頭也照樣算單。
- 沒設關鍵字的群組：用下面的自動判斷。
- 群組裡只有 `ALLOWED_USER_IDS` 的人能改關鍵字，其他人只能查看。在私訊打同樣的指令，會改你目前所在區的群組。
- `/關鍵字 全部`：這個群組每則訊息都當成單，適合整個群組都在派單的群。
- 搭配 `/即時 單`：只有跟你所在區有關的單才推給你，閒聊不推，也比較省推播額度。

## 單子怎麼判斷（沒設關鍵字的群組）

不需要固定格式，分三層判斷：
1. 以 `#單`、`【單】`、`派單`、`訂單`、`接單` 開頭，或內容有「單號」→ 一定是單
2. 規則打分：電話 +2，時間、日期、地點（路/街/號、基隆各區）、金額、任務（交車、接送、維修、拖吊、誰有空…）、車（Model Y、車牌）各 +1，**滿 3 分就是單**
   - 例：「明天早上10點 基隆火車站 Model Y 交車 0912-345-678」→ 是單
   - 例：「收到」「我到了」「早安」→ 不是單
3. **選填 Claude**：在 `.env` 填 `ANTHROPIC_API_KEY`，有任何跡象（1 分以上）的訊息會交給 Claude 判斷，並產生一行摘要（例如「📝 交車｜明天10點｜基隆站」）。
   Claude 判斷失敗時會自動退回規則判斷。每則疑似單子的訊息會呼叫一次 API，用量大的話可以把 `CLAUDE_MODEL` 改成 `claude-haiku-5-5` 省錢。

## 指令

私訊：`/最近`、`/單`、`/完成 編號`、`/即時 開|單|關`、`/關鍵字 …`、`/位置`、`/id`、`/說明`
群組：`/綁定 區名`、`/完成 編號`、`/關鍵字 …`

## 要注意的限制

- **機器人必須被加進每一個群組才看得到**：LINE 不允許程式讀取你個人帳號的聊天，只能讀機器人自己所在的群組。需要群組管理員同意把機器人（官方帳號）加進去。
- **只看得到加入之後的訊息**：LINE 不提供讀取群組歷史紀錄的 API，機器人只能記錄它進群組之後的對話。
- **定位要手動傳**：LINE 不允許機器人在背景追蹤位置，需要你按「傳送位置」。（之後可以加一個 LIFF 網頁，打開就自動抓 GPS。）
- **推播額度**：回覆你（reply）是免費的；但「轉發到群組」和「即時轉發」是 push，會算進官方帳號每月免費訊息額度（台灣輕用量方案約 200 則/月）。量大的話可以 `LIVE_FORWARD_DEFAULT=off` 或升級方案。
- **被標記的人必須在該群組內**，而且機器人要看過他發言過才知道他的名字（`@名字` 比對的是群組顯示名稱）。
- 群組訊息會出現為「機器人」發送，開頭帶你的名字。

```bash
npm test     # 用假的 LINE API 跑完整流程測試
```

程式結構：`src/server.js`（webhook）、`src/bot.js`（主要邏輯）、`src/mention.js`（@標記 → textV2）、
`src/orders.js`（單子判斷）、`src/regions.js`（距離計算）、`src/db.js`（SQLite）、`src/line.js`（LINE API）。
